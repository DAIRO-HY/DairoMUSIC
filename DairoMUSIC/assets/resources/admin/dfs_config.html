运行方式 (歌曲、图片、视频文件都保存在DairoDFS)
安装
安装包在 GitHub Releases 下载,选择当前系统的版本; “推荐地址”会自动获取最新版本。重新安装就是更新版本,DFS里的数据不受影响
内置DFS设置 (不填时使用默认值,修改后自动重启DFS)
DFS第一次启动时,用这个账号创建管理员,DairoMUSIC用它保存文件;密码不填时自动生成。 如果DFS已经初始化过,请填写DFS里已有的管理员账号
外部DFS
DFS账号需要在“我的”页面里开启公开访问路径;建议在DFS的用户管理里把这个账号设置为不处理上传的文件
